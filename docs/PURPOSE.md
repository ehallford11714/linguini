# Purpose

Linguini uses the **full NLP suite** and a **tooling library** (local + discoverable MCP servers) to:

1. **Ground** a purpose in evidence  
2. **Lean back** — chain existing tools when they already satisfy the purpose  
3. **Forge** native novel ops only when a verified gap remains  
4. **Verify** with a real unit-test loop (persist only on green)  
5. **Save** natives for future CLI/MCP reuse
